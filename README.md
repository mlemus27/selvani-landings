# Selvaní · Fracción Pionera — landings del VSL

Dos páginas estáticas, cada una un único archivo HTML, construidas sobre el VSL de Jorge.

- **Sincronía** (`4-sincronia/`) — el video queda fijo y el guion por capítulos se ilumina a medida que avanza; tocar un capítulo salta a ese minuto.
- **El módulo** (`5-modulo/`) — carta larga, con un diagrama del mecanismo que se arma al bajar.

El video se sirve desde Panda Video. Las fotos son del territorio real en Norcasia, Caldas. Tipografía: Zalando Sans (Google Fonts).

`.nojekyll` está a propósito: sin él, GitHub Pages ignora `_media/` por empezar con guion bajo y las páginas salen sin imágenes.

Las notas de trabajo de estas páginas no viven en este repo.
